stringbuffer in java
StringBuffer in Java is a class used to create mutable (modifiable) strings. It is part of the java.lang package and provides methods to manipulate strings without creating new objects, which can be more efficient in certain situations compared to using String. Here are some key features and methods of StringBuffer:


StringBuffer sb = new StringBuffer("Hello");
// Append
sb.append(" World");
// Insert
sb.insert(5, ", Java");
// Replace
sb.replace(0, 5, "Hi");
// Delete
sb.delete(3, 8);
// Reverse
sb.reverse();
System.out.println(sb); // Outputs the modified string

2. Common Methods:

append(): Adds text to the end of the buffer.

insert(): Inserts text at a specified position.

replace(): Replaces text within the buffer.

delete(): Removes text from the buffer.

reverse(): Reverses the contents of the buffer.

length(): Returns the length of the buffer.

capacity(): Returns the current capacity of the buffer.

charAt(): Returns the character at a specific index.
